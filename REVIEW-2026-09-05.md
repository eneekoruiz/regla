# Aura: independent review and UI/UX improvements

Reviewed on 5 September 2026 against the files in this workspace. This is an evidence-based review, not a production or clinical certification. The pasted Antigravity report is **not completely correct for this copy of the project**. It mixes implemented features, outdated measurements, missing components, and stronger assurances than the evidence supports.

## UI/UX delivered

- Warmer light palette, a quiet forest-green dark theme, editorial display typography and consistent rounded surfaces. No remote font dependency or decorative image downloads.
- More compact mobile timeline and first-use summary; no empty progress ring before the first recorded cycle.
- Cycle-phase control with a text label and help access, a clearer progress ring, and explicit estimate wording. An overdue period no longer appears to reset the home summary's cycle day automatically.
- Corrected a milestone-index edge case: a one-day delay no longer skips the current expected period and advances to the following cycle. Added a regression test for the overdue date.
- The summary identifies whether the estimate comes from recorded cycles or initial settings, so users can see when there is not yet enough history to personalize it.
- Calendar entries now distinguish recorded bleeding from estimated bleeding visually, and the legend explains the difference directly.
- Distinct, accessible everyday logging actions; clear empty state and supporting copy.
- Tools grouped into understanding the cycle, everyday care and managing personal records. Compact, full-width rows on mobile improve scanning and touch access.
- Consistent entry-screen branding, with a desktop introduction and a simpler mobile form.
- Softer dialog surfaces, a sticky save footer, keyboard dismissal and restored focus. Main-view changes focus the new content.
- Corrected invalid calendar-legend definition-list markup and chat keyboard focus escaping when Send is disabled. Added short-landscape navigation adjustments and fixed Selenium to scroll its target clear of the fixed navigation before performing a real click.
- Installation available from navigation and Settings → Mis datos. The native prompt is used when offered by the browser; otherwise a manual guide is shown. Only `appinstalled` confirms success. No unsolicited installation popup.
- Fixed primary-button hover contrast. Heavy-bleeding guidance appears before the normal diary content for today's very-heavy-flow record.
- Development-server watching excludes generated test artifacts, which previously triggered spurious reloads and a Windows file-lock crash during visual checks.

## Remaining boundaries

The local UI and automated checks can be reviewed here. The Neon schema and migration were verified from this workspace, but a public deployment, real Resend delivery and two-device synchronization test still need a configured HTTPS host and provider credentials. Installation simulations do not replace Safari/iOS and Android installation checks on physical devices. Automated accessibility checks and screenshot inspection do not replace a screen-reader usability study. Users' preferences and real usage are needed to validate whether the design works better for them.

Clinical and legal content still needs qualified review before public release. Aura's calendar estimates must not be used for contraception, diagnosis or confirmation of ovulation. Live browser storage remains plaintext at application level; the new encrypted backup protects exported files only and does not create automatic cloud backups. See `docs/PRODUCTION-READINESS.md` for the release gates and the three privacy deployment choices.

## Sources for the correction to the clinical claims

- [FIGO Ovulatory Disorders Classification System](https://pmc.ncbi.nlm.nih.gov/articles/PMC9527465/): adult menstrual frequency and the limits of inferring ovulatory function.
- [Bull et al., 2019: Real-world menstrual cycle characteristics of more than 600,000 menstrual cycles](https://www.nature.com/articles/s41746-019-0152-7): observed variation in both cycle and luteal-phase length. Citing this study does not validate Aura's algorithm.
